# P7 Ćirilica — plan izvršavanja

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kupac bira latinicu ili ćirilicu; kupčev dio sajta, mejlovi i Viber stižu na izabranom pismu.

**Architecture:** Mašinsko preslovljavanje na izlazu — u pregledaču nad DOM-om `(shop)` layouta (poslije hidratacije, `MutationObserver`), na serveru nad gotovim HTML-om mejla. Pismo putuje kolačićem `pismo` u pregledaču i zaglavljem `X-Pismo` do API-ja, a pamti se na `User`, `Order` i `GuestOrderRequest`.

**Tech Stack:** Next 15 / React 19 (App Router), ASP.NET Core 9 + EF Core (Postgres), xUnit, `node --test` (Node 24 sam skida TS tipove).

**Spec:** `docs/superpowers/specs/2026-10-15-p7-cirilica-design.md`

## Global Constraints

- Jezik je jedan (srpski), mijenja se samo pismo; podrazumijevano je **latinica**.
- Admin (`/admin`) i vozačka aplikacija ostaju na latinici.
- Pravila preslovljavanja su ista u TS i C#, a dokaz je zajednički `docs/pismo-vektori.json`.
- Root layout **ne čita kolačić na serveru** (inače statičke stranice postaju dinamičke).
- Enum na žici je PascalCase string (`"Latinica"`/`"Cirilica"`), ulaz `TryParse` + `IsDefined`, validator počinje sa `Input NotNull`.
- Ijekavica u svim novim tekstovima i komentarima.
- Frontend je gotov tek poslije `tsc`, `lint` **i** `npm run build` (dev server ugašen za build).

## Review Focus

1. **React piše u čvor koji je preslovljen** (promjena količine u korpi, odbrojavanje svake sekunde) → novi tekst se opet preslovi, bez petlje posmatrača. Test: vektor idempotentnosti + živa provjera odbrojavanja na početnoj.
2. **Kod/e-mail/URL usred rečenice** („Potvrda je poslana na marko@example.com", „Popust (UITEST5)") → samo riječi se preslovljavaju, token ostaje. Test: vektori u Tasku 1.
3. **HTML mejla sa `href` i entitetima** (`&amp;`, `&nbsp;`) → link i entitet netaknuti. Test: Task 2.
4. **Pretplatna narudžba** nastaje bez HTTP zahtjeva → pismo vlasnika, ne latinica. Test: Task 3.
5. **Admin sa kolačićem `cir`** → admin ostaje latinica i nije sakriven. Test: živa provjera u Tasku 6.
