# P4 — Marketinška početna: plan implementacije

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Početna `/` prodaje korpicu: hero sa cijenom „od" i odbrojavanjem do roka, „Kako funkcioniše", domaćini sa artiklima, utisci koje unosi admin, česta pitanja sa brojevima sa servera.

**Architecture:** Backend dobija tri aditivne izmjene: sljedeći krug u `SedmicaDto`, entitet `Utisak` sa javnim i admin endpointima, i `Artikli` na `ProducerDto`. Frontend razbija početnu na komponente u `components/pocetna/`, vadi imena dana u `lib/sedmica.ts`, a footer prestaje kucati rok.

**Tech Stack:** ASP.NET Core 9, EF Core 9 + PostgreSQL, MediatR, FluentValidation, xUnit + SQLite in-memory; Next.js 15 App Router, TypeScript, Tailwind v4, TanStack Query, lucide-react.

**Spec:** `docs/superpowers/specs/2026-10-14-p4-pocetna-design.md`

## Global Constraints

Ista pravila kao P2b i P3, ništa novo:

- **Omotnica odgovora:** svaki endpoint vraća `{ data, error, meta }` preko `Envelope`/`EnvelopeList`/`EnvelopeCreated` iz `ApiControllerBase`. Nikad `Ok(dto)`.
- **Identifikator greške je DRUGI argument konstruktora.** `new NotFoundException("Poruka.")`; `DomainException`→400, `NotFoundException`→404, `ConflictException`→409.
- **JSON izostavlja null** (`WhenWritingNull`): nullable polje je na žici odsutno. TS koristi `?:`, nikad `| null`.
- **`TestDb` dijeli jedan `DbContext`**; test koji tvrdi nešto o učitanim podacima zove `t.Db.ChangeTracker.Clear()`.
- **Nova NOT NULL kolona dobija eksplicitan `defaultValue`** u migraciji (ovdje je cijela tabela nova, pa ne važi).
- **Testovi rade na SQLite** preko `EnsureCreated()` — migracije se u testovima ne izvršavaju.
- `dotnet ef` se pokreće preko `AppDbContextFactory`: oba projekta `src/EPiljara.Infrastructure`, `--configuration Release` (živi API drži Debug DLL-ove zaključane).
- Srpski/ijekavica u porukama i tekstovima; identifikatori grešaka `snake_case`.
- `npm run build` **samo** u zadnjem tasku i **samo** sa ugašenim dev serverom (dijeli `.next` sa njim).
- **Kontrast WCAG AA** (4.5:1 za sitan tekst) za svaki novi par tekst/podloga. Bijeli tekst na `sand` pada — ne koristiti.
- **`useSearchParams()` mora biti u `<Suspense>`** — P4 ga ne treba nigdje; ne uvoditi ga.
- **Nema izmišljenih brojeva u tekstu:** rok, dan isporuke, prag i iznos popusta dolaze sa servera (spec, O4).
- **Nema seedovanih utisaka**, ni u demo seedu (spec, O2).

## Review Focus

1. **Odbrojavanje kad sat klijenta odstupa od servera.** Brojač dođe do nule a server još kaže `rokIstekao: false` → mora pisati „Rok je upravo istekao", ne negativne brojeve ni prazan blok. Pokriveno ručnom provjerom u Tasku 8 (pomjeren `CutoffHours`).
2. **Početna na praznoj instalaciji** (nema korpica, utisaka, slotova): nijedna sekcija ne smije pisati „od NaN KM", „od Infinity KM", „undefined" ni prazan naslov. Pokriveno u Tasku 5 i 6 (eksplicitna grana za praznu listu) i ručno u Tasku 8.
3. **Utisak sa dugim tekstom ili bez mjesta** — kartica ne smije prikazati „Marija, " sa visećim zarezom. Pokriveno u Tasku 6 (uslovni separator).
4. **Rok sa minutama** (`TimeFrom = "16:30"`) — `rokTekst` ne smije reći „u 16h" kad je rok 16:30. Pokriveno u Tasku 4.
5. **Admin briše utisak koji je na početnoj** — javna lista se mora osvježiti (`["utisci"]` invalidiran), inače admin misli da brisanje nije uspjelo. Pokriveno u Tasku 7.

```csharp
using EPiljara.Application.Common.Interfaces;
using EPiljara.Application.DTOs;
using EPiljara.Domain.Common;
using EPiljara.Domain.Entities;
using FluentValidation;
using MediatR;
using Microsoft.EntityFrameworkCore;

namespace EPiljara.Application.Features.Utisci;

internal static class UtisakMapiranje
{
    public static UtisakDto ToDto(this Utisak u) => new()
    {
        Id = u.Id,
        Ime = u.Ime,
        Mjesto = u.Mjesto,
        Tekst = u.Tekst,
        Objavljen = u.Objavljen,
        Redoslijed = u.Redoslijed,
    };

    /// <summary>Jedini redoslijed utisaka — i početna i admin ih vide istim redom.</summary>
    public static IQueryable<Utisak> PoRedu(this IQueryable<Utisak> q) =>
        q.OrderBy(u => u.Redoslijed).ThenBy(u => u.Kreiran);
}

/* ---------- Javno ---------- */

public record GetUtisciQuery : IRequest<IReadOnlyList<UtisakDto>>;

public class GetUtisciHandler(IAppDbContext db) : IRequestHandler<GetUtisciQuery, IReadOnlyList<UtisakDto>>
{
    public async Task<IReadOnlyList<UtisakDto>> Handle(GetUtisciQuery q, CancellationToken ct)
    {
        var utisci = await db.Utisci.Where(u => u.Objavljen).PoRedu().ToListAsync(ct);
        return utisci.Select(u => u.ToDto()).ToList();
    }
}

/* ---------- Admin ---------- */

public record GetAdminUtisciQuery : IRequest<IReadOnlyList<UtisakDto>>;

public class GetAdminUtisciHandler(IAppDbContext db) : IRequestHandler<GetAdminUtisciQuery, IReadOnlyList<UtisakDto>>
{
    public async Task<IReadOnlyList<UtisakDto>> Handle(GetAdminUtisciQuery q, CancellationToken ct)
    {
        var utisci = await db.Utisci.PoRedu().ToListAsync(ct);
        return utisci.Select(u => u.ToDto()).ToList();
    }
}

public record UtisakInput(string Ime, string? Mjesto, string Tekst, bool Objavljen, int Redoslijed);

public class UtisakInputValidator : AbstractValidator<UtisakInput>
{
    public UtisakInputValidator()
    {
        // Provjera ide nad trimovanom vrijednošću — handler upisuje trimovano, pa bi
        // „  M  " inače prošlo validaciju i u bazu ušlo kao „M".
        RuleFor(x => (x.Ime ?? "").Trim()).Length(2, 60)
            .WithName("Ime").OverridePropertyName("ime")
            .WithMessage("Ime mora imati od 2 do 60 znakova.");
        RuleFor(x => (x.Mjesto ?? "").Trim()).MaximumLength(60)
            .WithName("Mjesto").OverridePropertyName("mjesto")
            .WithMessage("Mjesto može imati najviše 60 znakova.");
        RuleFor(x => (x.Tekst ?? "").Trim()).Length(10, 500)
            .WithName("Tekst").OverridePropertyName("tekst")
            .WithMessage("Utisak mora imati od 10 do 500 znakova.");
        RuleFor(x => x.Redoslijed).InclusiveBetween(0, 999)
            .WithMessage("Redoslijed mora biti između 0 i 999.");
    }
}

public record CreateUtisakCommand(UtisakInput Input) : IRequest<UtisakDto>;

public class CreateUtisakValidator : AbstractValidator<CreateUtisakCommand>
{
    public CreateUtisakValidator() => RuleFor(x => x.Input).SetValidator(new UtisakInputValidator());
}

public class CreateUtisakHandler(IAppDbContext db) : IRequestHandler<CreateUtisakCommand, UtisakDto>
{
    public async Task<UtisakDto> Handle(CreateUtisakCommand cmd, CancellationToken ct)
    {
        var u = new Utisak();
        Upisi(u, cmd.Input);
        db.Utisci.Add(u);
        await db.SaveChangesAsync(ct);
        return u.ToDto();
    }

    internal static void Upisi(Utisak u, UtisakInput input)
    {
        u.Ime = input.Ime.Trim();
        u.Mjesto = (input.Mjesto ?? "").Trim();
        u.Tekst = input.Tekst.Trim();
        u.Objavljen = input.Objavljen;
        u.Redoslijed = input.Redoslijed;
    }
}

public record UpdateUtisakCommand(Guid Id, UtisakInput Input) : IRequest<UtisakDto>;

public class UpdateUtisakValidator : AbstractValidator<UpdateUtisakCommand>
{
    public UpdateUtisakValidator() => RuleFor(x => x.Input).SetValidator(new UtisakInputValidator());
}

public class UpdateUtisakHandler(IAppDbContext db) : IRequestHandler<UpdateUtisakCommand, UtisakDto>
```

```ts
import type { Sedmica } from "@/types/domain";

// Dva padeža za dane u sedmici — "u" traži akuzativ, "do" traži genitiv, i nisu isti
// oblik (npr. "petak" → "petka", ne "petaku"). Indeks je JS Date.getDay() (0 = nedjelja).
export const DANI_AKUZATIV = ["nedjelju", "ponedjeljak", "utorak", "srijedu", "četvrtak", "petak", "subotu"];
export const DANI_GENITIV = ["nedjelje", "ponedjeljka", "utorka", "srijede", "četvrtka", "petka", "subote"];

/** Sat roka: "16h", ili "16:30h" kad rok nije na puni sat — inače bi „u 16h" lagalo za pola sata. */
function sat(d: Date): string {
  const m = d.getMinutes();
  return m === 0 ? `${d.getHours()}h` : `${d.getHours()}:${String(m).padStart(2, "0")}h`;
}

/** "utorka u 16h" — ide iza "do". */
export function rokTekst(rok: Date): string {
  return `${DANI_GENITIV[rok.getDay()]} u ${sat(rok)}`;
}

/** "četvrtak 15.10." — ide iza "u". */
export function isporukaTekst(d: Date): string {
  return `${DANI_AKUZATIV[d.getDay()]} ${d.getDate()}.${d.getMonth() + 1}.`;
}

/**
 * Krug za koji se TRENUTNO naručuje. Do roka je to tekuća sedmica; poslije roka
 * checkout prodaje za narednu (backend `SedmicaHelper.SedmicaZaNarudzbu`), pa i
 * odbrojavanje, FAQ i footer govore o narednoj.
 */
export function aktivniKrug(s: Sedmica): { rok: Date; isporuka: Date; zaSljedecu: boolean } {
  return s.rokIstekao
    ? { rok: new Date(s.sljedeciRok), isporuka: new Date(s.sljedecaIsporuka), zaSljedecu: true }
    : { rok: new Date(s.rokNarucivanja), isporuka: new Date(s.datumIsporuke), zaSljedecu: false };
}
```

```tsx
"use client";

import { useEffect, useState } from "react";
import { useQueryClient } from "@tanstack/react-query";
import { queryKeys, useSedmica } from "@/lib/api/hooks";
import { aktivniKrug, isporukaTekst, rokTekst } from "@/lib/sedmica";

const DAN = 86_400;

function rastavi(ms: number) {
  const s = Math.max(0, Math.floor(ms / 1000));
  return {
    dani: Math.floor(s / DAN),
    sati: Math.floor((s % DAN) / 3600),
    minute: Math.floor((s % 3600) / 60),
    sekunde: s % 60,
  };
}

/**
 * Odbrojavanje do roka naručivanja za krug koji je trenutno otvoren (vidi `aktivniKrug`).
 *
 * Sat se čita tek u efektu: početna je klijentska, ali je Next ipak prerenderuje, pa bi
 * `Date.now()` u renderu dao različit tekst na serveru i klijentu (greška hidratacije).
 *
 * Kad brojač dođe do nule, sedmica se ponovo traži sa servera — server odlučuje da je rok
 * prošao i prebacuje na sljedeći krug. Dok odgovor ne stigne (ili ako je sat klijenta
 * ispred serverskog), piše „Rok je upravo istekao" umjesto nula ili negativnih brojeva.
 */
export function Odbrojavanje() {
  const { data } = useSedmica();
  const qc = useQueryClient();
  const [sada, setSada] = useState<number | null>(null);

  useEffect(() => {
    setSada(Date.now());
    const id = setInterval(() => setSada(Date.now()), 1000);
    return () => clearInterval(id);
  }, []);

  const krug = data ? aktivniKrug(data) : null;
  const preostalo = krug && sada !== null ? krug.rok.getTime() - sada : null;
  const istekao = preostalo !== null && preostalo <= 0;

  useEffect(() => {
    if (istekao) qc.invalidateQueries({ queryKey: queryKeys.sedmica() });
  }, [istekao, qc]);

  if (!krug || preostalo === null) return null;

  const { dani, sati, minute, sekunde } = rastavi(preostalo);
  // Sekunde tek u posljednja 24 sata (spec, O8) — do tada stranica ne treba da treperi.
  const polja: [number, string][] = [
    [dani, "dana"],
    [sati, "sati"],
    [minute, "min"],
    ...(dani === 0 ? ([[sekunde, "sek"]] as [number, string][]) : []),
  ];

  return (
    <div className="rounded-card border border-line bg-sand/60 p-4" aria-live="off">
      <p className="text-xs font-bold uppercase tracking-[0.14em] text-brand-700">
        {krug.zaSljedecu ? "Ova sedmica je zatvorena — rok za sljedeću" : "Do roka za ovu sedmicu"}
      </p>
```

```ts
    odgovor: ({ popust }) =>

      (popust
        ? `Prvih ${popust.odIsporuke - 1} isporuka plaćaš punu cijenu, a od ${popust.odIsporuke}. isporuke je korpica ${popust.procenat}% jeftinija. `
        : "") +

/**
 * Sklapa kontekst iz sedmice i liste korpica. Popust se čita iz korpice čija je
 * `cijenaSaPretplatom` niža od pune (spec, O5) — klijent ne zna pravilo, samo ga čita.
 */
export function kontekstPitanja(sedmica?: Sedmica, korpice?: Korpica[]): KontekstPitanja {
  const k: KontekstPitanja = {};

  if (sedmica) {
    const krug = aktivniKrug(sedmica);
    k.rok = { tekst: rokTekst(krug.rok), zaSljedecu: krug.zaSljedecu };
    k.isporuka = isporukaTekst(krug.isporuka);
  }

  const sPopustom = korpice?.find(
    (x) =>
      x.cijenaSaPretplatom !== undefined &&
      x.isporukaDoPopusta !== undefined &&
      x.cijena > 0 &&
      x.cijenaSaPretplatom < x.cijena,
  );
  if (sPopustom) {
    k.popust = {
      procenat: Math.round((1 - sPopustom.cijenaSaPretplatom! / sPopustom.cijena) * 100),
      odIsporuke: sPopustom.isporukaDoPopusta! + 1,
    };
  }

  return k;
}
```

```tsx
}: {
  open: boolean;
  onClose: () => void;
  utisak?: Utisak | null;
}) {
  const qc = useQueryClient();
  const { show } = useToast();
  const [form, setForm] = useState(PRAZNO);
  const [errors, setErrors] = useState<Record<string, string[]>>({});

  useEffect(() => {
    if (!open) return;
    setErrors({});
    setForm(
      utisak
        ? {
            ime: utisak.ime,
            mjesto: utisak.mjesto,
            tekst: utisak.tekst,
            objavljen: utisak.objavljen,
            redoslijed: String(utisak.redoslijed),
          }
        : PRAZNO,
    );
  }, [open, utisak]);

  const mutation = useMutation({
    mutationFn: (body: UtisakInput) =>
      utisak ? adminApi.updateUtisak(utisak.id, body) : adminApi.createUtisak(body),
    onSuccess: () => {
      // Oba ključa: admin lista i javna lista na početnoj (Review Focus 5).
      qc.invalidateQueries({ queryKey: queryKeys.adminUtisci() });
      qc.invalidateQueries({ queryKey: queryKeys.utisci() });
      show(utisak ? "Utisak ažuriran" : "Utisak dodan");
      onClose();
    },
    onError: (err) => {
      if (err instanceof ApiRequestError) setErrors(err.fieldErrors);
    },
  });

  function submit(e: React.FormEvent) {
    e.preventDefault();
    setErrors({});
    mutation.mutate({
      ime: form.ime,
      mjesto: form.mjesto || undefined,
      tekst: form.tekst,
      objavljen: form.objavljen,
      redoslijed: Number(form.redoslijed) || 0,
    });
  }

  if (!open) return null;

  return (
    <div className="fixed inset-0 z-50">
      <button aria-label="Zatvori" onClick={onClose} className="absolute inset-0 bg-black/40" />
      <div className="absolute right-0 top-0 flex h-full w-full max-w-lg flex-col bg-cream shadow-xl">
        <div className="flex items-center justify-between border-b border-line px-6 py-4">
          <h2 className="font-display text-lg font-bold">{utisak ? "Uredi utisak" : "Novi utisak"}</h2>
          <button onClick={onClose} className="rounded-full p-1.5 hover:bg-sand" aria-label="Zatvori">
            <X className="h-5 w-5" />
          </button>
        </div>

        <form onSubmit={submit} className="flex-1 space-y-4 overflow-y-auto p-6">
          <Field label="Ime kupca" required error={errors["input.ime"]?.[0]}>
            <Input
              value={form.ime}
              onChange={(e) => setForm({ ...form, ime: e.target.value })}
              placeholder="npr. Marija P."
              maxLength={60}
            />
          </Field>

          <Field label="Mjesto" error={errors["input.mjesto"]?.[0]}>
            <Input
              value={form.mjesto}
              onChange={(e) => setForm({ ...form, mjesto: e.target.value })}
              placeholder="npr. Borik"
              maxLength={60}
            />
          </Field>

          <Field label="Utisak" required error={errors["input.tekst"]?.[0]}>
            <Textarea
              value={form.tekst}
              onChange={(e) => setForm({ ...form, tekst: e.target.value })}
              rows={5}
              maxLength={MAKS_TEKST}
            />
            <p className="mt-1 text-right text-xs text-muted">
              {form.tekst.length}/{MAKS_TEKST}
            </p>
          </Field>

          <Field label="Redoslijed (manji ide prvi)" error={errors["input.redoslijed"]?.[0]}>
            <Input
              type="number"
              min={0}
              max={999}
              value={form.redoslijed}
              onChange={(e) => setForm({ ...form, redoslijed: e.target.value })}
            />
          </Field>

          <label className="flex items-center gap-2 text-sm text-ink">
            <input
              type="checkbox"
              checked={form.objavljen}
              onChange={(e) => setForm({ ...form, objavljen: e.target.checked })}
              className="h-4 w-4 accent-brand-600"
            />
            Objavljen na početnoj
          </label>

          <Button type="submit" className="w-full" disabled={mutation.isPending}>
            {mutation.isPending ? "Čuvam…" : "Sačuvaj"}
          </Button>
        </form>
      </div>
    </div>
  );
}
```

Uskladi sa stvarnim potpisom `Field` (pogledaj `components/ui/field.tsx`: da li prima `required` i `error`, i da li `children` smije imati više elemenata). Ako `Field` ne prihvata više djece, stavi brojač ispod `Field`-a.

```tsx
"use client";

import { useState } from "react";
import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { Pencil, Plus, Trash2, X } from "lucide-react";
import { Button } from "@/components/ui/button";
import { LoadingBlock } from "@/components/ui/spinner";
import { UtisakForm } from "@/components/admin/utisak-form";
import { useToast } from "@/components/ui/toast";
import { adminApi } from "@/lib/api/endpoints";
import { ApiRequestError } from "@/lib/api/client";
import { queryKeys } from "@/lib/api/hooks";
import type { Utisak } from "@/types/domain";

export default function AdminUtisciPage() {
  const qc = useQueryClient();
  const { show } = useToast();
  const [editing, setEditing] = useState<Utisak | null>(null);
  const [open, setOpen] = useState(false);
  const [confirmId, setConfirmId] = useState<string | null>(null);

  const utisci = useQuery({
    queryKey: queryKeys.adminUtisci(),
    queryFn: () => adminApi.utisci(),
  });

  const remove = useMutation({
    mutationFn: (id: string) => adminApi.deleteUtisak(id),
    onSuccess: () => {
      qc.invalidateQueries({ queryKey: queryKeys.adminUtisci() });
      qc.invalidateQueries({ queryKey: queryKeys.utisci() });
      setConfirmId(null);
      show("Utisak obrisan");
    },
    onError: (err) => {
      setConfirmId(null);
      show(err instanceof ApiRequestError ? err.message : "Brisanje nije uspjelo", "error");
    },
  });

  return (
    <div className="space-y-6">
      <div className="flex items-center justify-between">
        <div>
          <h1 className="font-display text-2xl font-bold">Utisci</h1>
          <p className="text-muted">Šta kupci kažu — prikazuje se na početnoj, samo objavljeni.</p>
        </div>
        <Button
          onClick={() => {
            setEditing(null);
            setOpen(true);
          }}
        >
          <Plus className="h-4 w-4" /> Novi utisak
        </Button>
      </div>

      {utisci.isLoading ? (
        <LoadingBlock />
      ) : !utisci.data?.length ? (
        <p className="rounded-card bg-white p-6 text-muted shadow-card">
          Još nema utisaka. Dok nijedan nije objavljen, sekcija se na početnoj ne prikazuje.
        </p>
      ) : (
        <div className="overflow-hidden rounded-card bg-white shadow-card">
          <ul className="divide-y divide-line">
            {utisci.data.map((u) => {
              const confirming = confirmId === u.id;
              return (
                <li key={u.id} className="flex items-start gap-4 p-4">
                  <div className="min-w-0 flex-1">
                    <p className="font-medium">
                      {u.ime}
                      {u.mjesto && <span className="font-normal text-muted"> · {u.mjesto}</span>}
                      <span
                        className={
                          u.objavljen
                            ? "ml-2 rounded-full bg-brand-50 px-2 py-0.5 text-xs font-medium text-brand-700"
                            : "ml-2 rounded-full bg-sand px-2 py-0.5 text-xs font-medium text-ink/80"
                        }
                      >
                        {u.objavljen ? "Objavljen" : "Skriven"}
                      </span>
                    </p>
                    <p className="mt-1 line-clamp-2 text-sm text-muted">{u.tekst}</p>
                    <p className="mt-1 text-xs text-muted">Redoslijed: {u.redoslijed}</p>
                  </div>

                  {confirming ? (
                    <div className="flex items-center gap-2">
                      <Button size="sm" variant="danger" onClick={() => remove.mutate(u.id)} disabled={remove.isPending}>
                        Obriši
                      </Button>
                      <button
                        onClick={() => setConfirmId(null)}
                        className="grid h-9 w-9 shrink-0 place-items-center rounded-full text-muted transition hover:bg-sand hover:text-ink"
                        aria-label="Otkaži"
                      >
                        <X className="h-4 w-4" />
                      </button>
                    </div>
                  ) : (
                    <>
                      <button
                        onClick={() => {
                          setEditing(u);
                          setOpen(true);
                        }}
                        className="grid h-9 w-9 shrink-0 place-items-center rounded-full text-muted transition hover:bg-sand hover:text-ink"
                        aria-label="Uredi"
                      >
                        <Pencil className="h-4 w-4" />
                      </button>
                      <button
                        onClick={() => setConfirmId(u.id)}
                        className="grid h-9 w-9 shrink-0 place-items-center rounded-full text-muted transition hover:bg-red-50 hover:text-red-600"
                        aria-label="Obriši"
                      >
                        <Trash2 className="h-4 w-4" />
                      </button>
                    </>
                  )}
                </li>
              );
            })}
          </ul>
        </div>
      )}

      <UtisakForm open={open} onClose={() => setOpen(false)} utisak={editing} />
    </div>
  );
}
```
