- [ ] **Step 2: Zatraži je u runtime-u**

U `EPiljara.Driver/Services/LocationTracker.cs`, uz `ZatraziDozvoluAsync`:

```csharp
    /// <summary>Traži dozvolu za prikaz obavještenja (Android 13+). Odbijanje NE
    /// zaustavlja praćenje — servis i dalje radi, samo bez vidljivog obavještenja.</summary>
    public async Task<bool> ZatraziObavjestenjaAsync()
    {
        try
        {
            var status = await Permissions.CheckStatusAsync<Permissions.PostNotifications>();
            if (status != PermissionStatus.Granted)
                status = await Permissions.RequestAsync<Permissions.PostNotifications>();
            return status == PermissionStatus.Granted;
        }
        catch (Exception)
        {
            // Na starijim Androidima dozvola ne postoji; nedostatak nije greška.
            return false;
        }
    }
```

Pozovi je u `PokreniAsync`, odmah prije `#if ANDROID` bloka koji diže servis:

```csharp

```

Povratnu vrijednost namjerno ignorišemo — praćenje se pokreće bez obzira na nju.

- [ ] **Step 3: Objasni zašto tražiš lokaciju, prije nego što je zatražiš**

Spec traži da se dozvola traži „sa objašnjenjem zašto". U `RouteViewModel.PokreniPracenjeAsync`, prije `ZatraziDozvoluAsync`:

```csharp
    private bool _dozvolaTrazena;

    public async Task PokreniPracenjeAsync()
    {
        if (tracker is null) return;

        // Objašnjenje ide PRIJE sistemskog dijaloga, jednom po sesiji. Sistemski
        // dijalog ne nosi kontekst, a ovdje se traži lokacija za nešto što vozač
        // ne očekuje bez objašnjenja.
        if (!_dozvolaTrazena)

            var vec = await Permissions.CheckStatusAsync<Permissions.LocationWhenInUse>();
            if (vec != PermissionStatus.Granted && Application.Current?.Windows.Count > 0)

                    "Lokacija",
```

- [ ] **Step 1: M4 — pribij JSON ugovor prema mapi testom**

`map.html` čita imena polja `id`, `redni`, `lat`, `lon`, `gotova` doslovno; preimenovanje svojstva na C# strani tiho obori mapu i nijedan test to ne bi primijetio. Ovo je jedina prava rupa u pokrivenosti koju je pregled našao.

```csharp
    [Fact]
    public void Payload_za_mapu_drzi_imena_polja_koja_map_html_cita()
    {
        var vm = new RouteViewModel(null!, null!, null!);
        string? primljeno = null;
        vm.MapaTreba += b => primljeno = b;

        var stanica = Stanica(1, 44.7722, 17.1910);
        vm.Primijeni(Route(stanica));

        var json = Encoding.UTF8.GetString(Convert.FromBase64String(primljeno!));
        using var doc = JsonDocument.Parse(json);
        var prva = doc.RootElement[0];

        // map.html:40 i dalje čita tačno ova imena.
        Assert.Equal(stanica.OrderId.ToString(), prva.GetProperty("id").GetString());
        Assert.Equal(1, prva.GetProperty("redni").GetInt32());
        Assert.Equal(44.7722, prva.GetProperty("lat").GetDouble());
        Assert.Equal(17.1910, prva.GetProperty("lon").GetDouble());
        Assert.False(prva.GetProperty("gotova").GetBoolean());
    }

    [Fact]
    public void Stanica_bez_koordinata_salje_null_a_ne_nulu()
    {
        var vm = new RouteViewModel(null!, null!, null!);
        string? primljeno = null;
        vm.MapaTreba += b => primljeno = b;

        vm.Primijeni(Route(Stanica(1, 44.7722, 17.1910) with { Latitude = null, Longitude = null }));

        var json = Encoding.UTF8.GetString(Convert.FromBase64String(primljeno!));
        using var doc = JsonDocument.Parse(json);
        var prva = doc.RootElement[0];

        // Nula bi zabola pin na 0°N 0°E, u Atlantik.
        Assert.Equal(JsonValueKind.Null, prva.GetProperty("lat").ValueKind);
        Assert.Equal(JsonValueKind.Null, prva.GetProperty("lon").ValueKind);
    }
```

Test fajlu trebaju `using System.Text;` i `using System.Text.Json;` ako ih već nema.

- [ ] **Step 3: M1 — odvoji grešku popup-a od greške ekrana**

Isto `Error` svojstvo puni i crvenu traku na vrhu ekrana i poruku unutar popup-a. Posljedica: kad popup iskoči (a sada ga otvara GPS, ne vozač), nevezana greška učitavanja rute tiho nestane; obrnuto, „Narudžba je već zatvorena." ostane u traci na vrhu kao da je greška rute.

Dodaj zasebno svojstvo:

```csharp
    /// <summary>Greška unutar popup-a. Odvojena od <see cref="Error"/> jer traka na
    /// vrhu ekrana i poruka u popup-u imaju različit životni vijek — popup sada
    /// otvara GPS u bilo kom trenutku, pa bi dijeljeno svojstvo brisalo grešku
    /// učitavanja rute bez ijedne radnje vozača.</summary>
    [ObservableProperty] private string? _popupError;
```

Zatim u `RouteViewModel`:
- `PrikaziPopup`: `Error = null;` → `PopupError = null;`
- `Pozovi`: obje dodjele `Error` → `PopupError`
- `ZavrsiIzPopupaAsync`: `Error = null;` i dodjela u `catch` → `PopupError`

U `RoutePage.xaml`, red 112 (poruka **unutar** popup-a) veži na `PopupError`; red 26 (traka na vrhu) ostaje na `Error`.

**Ne dira M5–M10** (odjava sa `Pomjeraj` događaja, `Connectivity` osluškivanje, dva izvora istine za zatvoren status, mrtvi `fokusiraj()`, `UcitajAsync` mimo komande, zastarjela ručna provjera). Nijedan ne blokira optimizaciju rute; ostaju zapisani u pregledu.
